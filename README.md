# The BEST Keyboard 

 Hall effect switches, tri-mode wireless, per-key RGB, OLED display, rotary encoder, hot-swap sockets, 
and Qi wireless charging.

## What it is

Gateron Magnetic Jade switches have a magnet in the stem , 
and an SS49E hall effect sensor on the PCB reads the exact position 
of every key. So adjustable acutation points and basically infinite presses.

The MCU is an E73-2G4M08S1C nRF52840 module. It handles USB HID 
wired, BLE wireless, and a  2.4GHz dongle mode via 
Enhanced ShockBurst. The dongle is a 
separate small PCB.

84 SK6812MINI-E LEDs for per-key RGB. SSD1306 OLED for status 
display. EC11 encoder for volume or whatever you want. Qi receiver coil in the case 
bottom for wireless charging.
